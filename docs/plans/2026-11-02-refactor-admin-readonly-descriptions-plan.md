# Admin 只读描述信息统一

本独立有界计划执行用户已批准的九处建议，继承候选截图的范围及已完成的表单视觉修复基线。只更新只读信息的展示规则与对应页面，不改变产品 master、REL 的执行顺序、THEME-E1、候选或发布权威。先前已完成计划正文继续冻结；本计划明确替代旧规则中“所有系统元信息都使用只读输入框”的要求。

## 约定与范围

- Descriptions 仅用于同一业务组中至少三项独立只读信息；标题、重复内容、按钮、可编辑字段不计数。不为凑数增加字段。
- 本批描述信息默认单列、小号、无额外装饰性 Card；标识、摘要、地址正常换行，使用组件主题色。
- 账号四项已保存资料；运行健康五项；联系冲突五项固定当前值；主题包四项；编辑器版本六项；已验证线上概览三项；政策版本／摘要／生效日期三项；地点城市／地址／公开状态三项；单项当前版本改普通文本。
- 联系冲突的地点／社交仍是列表，政策正文比较及动作保留；内容“状态与发布”两项保留现有只读表单。支付凭据两项不纳入。
- API、权限、脏状态、完整 payload、保存／重置、版本核对、确认与恢复、Drawer 720px 及可视化编辑器协议保持原合同。
- 原工作区已有变更被保存为本批起始副本；只追加本批精确改动，不提交、推送、开 PR 或部署。
