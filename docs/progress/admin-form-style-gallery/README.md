## 证据轮次

同一网页默认“当前 · 用户反馈复核”，四个旧轮次标为历史并保留原图。旧的 `#page=…` 深链继续进入基础统一历史轮次，原 226 张图保留。当前深链使用 `#round=feedback&page=health&theme=light&view=side`。

2026-11-06 复核入口：01 的描述组件方案已撤回，两个入口恢复只读表单；02 对齐上方表单；03、08、04、05、09、07 标明用户已认可；06 未评价，保留待确认。01、02 共 12 张本次实拍，其余九处中的七处沿用 11 月 2 日原图。另集中展示前轮七个不同页面的最终效果（10 月 31 日原图），去除与 01 重复的账号入口，共 16 项、22 区域、88 个图片引用；引用复用不算新增实拍。

无需逐轮重看过程截图：本次重点看 02，补看未评价的 06；前轮结构修复可在当前入口集中看最终效果。更早基础统一与候选原图用于追溯，未要求重新逐张判断，也不冒称用户已认可全部历史页面。截图齐备、代码完成与用户认可分别记录。

分区与单列修复轮次图片来自 `docs/progress/assets/admin-form-visual-structure/`，与历史目录隔离。`generate.py` 为每个必需区域列出浅／深色 before／after；缺图显示“证据未齐”及已有单张基线，不伪造成对对比。新增实图后重新生成数据并刷新网页，当页核对主题、区域、滑动／并排及放大。图片齐备不代替业务测试和计划中的完成检查点。

直接用浏览器打开本目录的 `index.html` 即可使用；也可以在仓库根目录运行：

```sh
python3 docs/progress/admin-form-style-gallery/serve.py
```

访问 `http://127.0.0.1:4381/admin-form-style-gallery/`。支持按页面搜索、浅深色截图、区域切换、滑动／并排比较，以及原图 100%／200% 放大。地址中的 hash 保留当前入口、主题和区域。

表单基础统一轮次截图保留在相邻的 `../assets/admin-form-style-unification/`，无需复制或修改。`gallery-data.js` 由本目录 `generate.py` 从保留的截图生成，包含 27 组对比、43 个区域及全部 226 张原图；另提供全后台排查原图入口。

重新生成目录：

```sh
python3 docs/progress/admin-form-style-gallery/generate.py
```

这是对已有证据的展示补充；原始索引、截图、审查和完成检查点保持原权威。
