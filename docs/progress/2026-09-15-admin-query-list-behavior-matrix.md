# Admin Query List Behavior and Disposition Matrix

This matrix freezes the observable baseline before page migration. `Preserve` means the behavior is
domain-authoritative, `converge` means the standard query-page contract replaces page-local
orchestration, and `remove` means the current behavior is unsafe or contradicts the accepted
contract. Target units own the page changes; this file is evidence, not a second execution queue.

## Shared U1 contract evidence

- `StandardListPageSpec.formRoute` is optional; list-only consumers receive a safe no-op navigation
  helper unless they supply `openFormPage`.
- `initialFormValues` seeds and resets visible controls independently from `initialFilters`, which
  remains the initial committed request scope.
- `toolbarExtra` and `buildTableNode` receive `appliedFilters`; draft edits do not change these
  values until Query commits them.
- The list controller binds a successful response to the request-filter object that produced it.
  A later replacement request clears mismatched rows before loading and remains blocking on failure.
  A failed same-scope refresh retains matching rows and surfaces the failure as a partial state.
  Older request completions cannot overwrite the latest request outcome.
