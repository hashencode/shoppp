## 共享消费者与合理例外

- StructuredContentEditor → ContentEditorPage（page/article）、PoliciesPage。无 barrel 或其他 workspace 生产消费者；按三入口验证。
- StorefrontResourcePicker → ThemeEditorPage（schema 与绑定）、NavigationPage（header/footer）。CatalogMediaPicker 与 StorefrontLinkEditor → ThemeEditorPage。按 shared suites、主题 Browser 与导航 Browser 验证，导航保留兼容截图。
- 商品色样是业务色值；色样＋HEX、图片宽高属于关联组合。报表日期是列表筛选。主题 workspace 与角色独立详情的树＋编辑列是专用布局，均不机械改成全页单列。
- 复杂资源／媒体 fieldset 提供组语义，修复边框 token 即可；无需把搜索、分页和结果拆成独立业务字段。动态内容只提供删除时不新增排序功能。
- 灰色文字源码命中不自动是表单缺陷：订单不可变事实和列表元数据不扩展为整站视觉重构。本报告只确认上表实际表单及关联操作区的问题。
- 无真实存储写入，视觉证据不证明真实发布成功；对应请求／恢复合同由现有 focused tests 与 Browser Mode 验证。
