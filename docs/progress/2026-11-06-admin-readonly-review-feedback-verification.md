## 同类问题排查与规则

源码检索覆盖 `apps/admin/src` 的 Descriptions、readonly／readOnly／isReadonly 分支，以及共享 BasicCrudFormRecipe、CrudFormDrawerRecipe；下面区分实际用途。未将源码检查称为所有角色与入口的完整浏览器回归。

| 用法 | 源码核对结论 |
| --- | --- |
| 账号、角色 | Drawer 与兼容入口使用共用 fields；只读通过 Form disabled 及动作权限控制。账号资料已恢复原输入框 |
| 地点 Drawer、店铺资料、配送、经营设置 | 相同字段和控件随权限只读；地点只读会隐藏编辑提示、增删动作，不替换字段结构 |
| 商品、商品集合、内容页面／文章 | 共用 renderFields／sections；readonly 保留输入控件，禁用编辑、隐藏写动作。内容状态与保存版本继续保留两项只读表单 |
| 已发布商品修订、导航、隐私 | 修订使用同一 Form.Item／控件并按 canEdit 禁用；导航和隐私没有按查看权限替换成 Descriptions 的分支 |
| 联系冲突核对 5 项、地点列表 3 项 | 独立恢复核对和列表摘要，分别于 03、08 获用户认可，不等同于地点编辑表单 |
| 主题包 4 项、编辑器审阅 6 项、政策审阅 3 项 | 独立资料／审阅摘要，04、05、07 获用户认可 |
| 线上概览 3 项 | 独立摘要，06 仍待用户判断 |
| 当前版本 1 项、发布历史 7 项、审批资料 4 项 | 单项采用普通文本；独立发布／审批摘要保留。09 获用户认可 |
| 订单事实 4 项 | 独立订单聚合信息，没有对应编辑表单；既有响应式多列不属于“查看时换样式”，本次不改其布局 |
| 模板退款 4 项、用户资料 5 项、步骤确认 4 项、成功结果 3 项 | 独立模板详情、流程确认或结果摘要，没有替代同一表单 readonly 的分支 |

未发现其他普通表单因进入查看模式而改用描述组件的确认实例。此结论针对上述源码用途及共享渲染边界，不宣称整个后台没有其他视觉问题。

`ai-rules.md` §4.4 与七份规则投影同步补足优先级：查看／编辑复用字段、顺序、分区、控件和宽度；原只读系统字段保留表单样式。仅独立只读摘要可考虑 Descriptions，同组至少三项是必要条件，不能单凭数量替换表单。原 11 月 2 日采用记录保留并追加明确的后续替代说明。
