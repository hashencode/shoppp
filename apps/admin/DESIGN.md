# DESIGN

## Status
`DESIGN.md` is now a lightweight design note file.
The authoritative, executable UI/UX rules are maintained in:

- `docs/ai/ai-rules.md` -> `Design Baseline (Authoritative)`

## Why
- Avoid rule drift between multiple documents.
- Keep AI implementation instructions in one canonical source.
- Keep this file for high-level context only.

## Design Direction (Non-normative)
- Template pages should feel consistent in state feedback and interaction affordances.
- Dark mode compatibility is required for all new UI work.
- Prefer clarity over decoration in admin workflows.
