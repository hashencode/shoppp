# 旧页迁移 PR 自检模板

适用范围：从 legacy admin 页面迁移到当前项目后，提交 PR 前的最小自检。

使用方式：复制到 PR 描述，逐项勾选；未满足项不要合并。

## 一、页面归类

- [ ] 已明确页面属于哪种 recipe：`list-query-standard` / `form-three-mode` / `profile` / `business override`
- [ ] 已说明为什么复用现有模板，而不是散装实现
- [ ] 若做了独立详情页，已说明为什么不能复用 `readonly` 表单

## 二、筛选区

- [ ] 普通筛选项已优先使用模板字段：`input` / `select` / `date` / `date-range`
- [ ] 没有使用 `custom + RangePicker` 实现日期范围
- [ ] 没有使用 `custom + Select` 实现可搜索下拉
- [ ] 筛选项变更不会自动触发查询，请求只在点击“查询”后发送（`重置` 除外）
- [ ] 桌面端已确认筛选项同行显示正常，没有因为自定义实现导致换行

## 三、表单与详情

- [ ] `add / modify / readonly` 模式行为完整
- [ ] 没有无依据设置 `requiredMark={false}`
- [ ] `readonly` 模式下保存/重置/提交动作已禁用或硬阻断
- [ ] 参数非法、详情失败、详情成功三种首屏状态已覆盖

## 四、路由与跳转

- [ ] 编辑/表单/详情页路径遵守“列表路径前缀 + 子路径”
- [ ] 路由组件只从 `react-router-dom` 引入 `Navigate` / `useNavigate`
- [ ] 已手工点测新增、编辑、查看入口，确认无运行时错误

## 五、列表内容区

- [ ] 操作列宽度已按“同一时刻可见的按钮集合”计算
- [ ] 若使用“更多”聚合，列宽已按聚合后的可见集合重算
- [ ] `ACTION_COLUMN_WIDTH` 上方有计算注释，且注释与常量一致
- [ ] 同域主标识列宽度已和现有页面对齐
- [ ] 同类资源编号列宽度已和现有页面对齐

## 六、权限与交互

- [ ] `readonly` 访问走读权限，`add/modify` 走写权限
- [ ] 行操作按钮权限已核对
- [ ] 至少验证过一种“有页面权限但无按钮权限”的场景
- [ ] 危险操作使用了二次确认

## 七、接口与状态

- [ ] 接口路径和方法已和 `docs/api/api.md` 对齐；若暂用 legacy 接口，已在 PR 说明中写明
- [ ] 关键路由参数（如 `id` / `resourceId` / `ownerId`）已显式校验
- [ ] 列表/详情已覆盖 `loading / empty / error / partial` 中适用状态

## 八、验证

- [ ] `bunx tsc --noEmit` 已通过
- [ ] 至少补了 1 条 happy path 测试
- [ ] 至少补了 1 条失败或边界测试
- [ ] 已完成一轮关键跳转链路手工点测
